Development

Environment
- Xcode 15.4+ (or Swift Playgrounds 4.3+)
- iOS 16+ Simulator target
- Swift tools 6.0 manifest (Package.swift is auto-generated by Playgrounds)

Open & Run
- Open the folder `VisualGo.swiftpm` directly in Xcode (File → Open…).
- Select the `VisAlGo` iOS app product and run on a simulator or device.

Coding Guidelines
- Keep logic in `AlgoVisualizerViewModel`; views should be mostly declarative.
- Prefer small, obvious animations with `withAnimation` over manual timing.
- Maintain color semantics (Blue default, Orange processing, Green visited, etc.).
- Mirror algorithm state for UI when helpful (e.g., queue/stack → `structureVisualizer`).

Adding Algorithms
- Array algorithms: Update `Algorithm` enum + descriptions, implement a `runX()` method, route in `runSelectedAlgorithm`, and add any parameter inputs in `AlgorithmControlsView`.
- Tree algorithms: Update `TreeAlgorithm`, implement `runX()` that updates both node colors and `structureVisualizer`, and route in `runSelectedTreeAlgorithm`.

Testing Tips
- Use the “Load Sample Case” button to quickly validate parsing and animations.
- For parsing issues, add temporary print statements or breakpoints in `setupArray`/`setupTree`.
- Validate edge cases: empty input, out-of-bounds indices, non-integer values for Prefix Sum.

Future Improvements
- Disable controls during animations, or add cancel/pause.
- Add speed controls for faster/slower playback.
- Deterministic animation drivers (e.g., timeline-based) for UI tests.
